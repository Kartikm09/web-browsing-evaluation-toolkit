# Methodology

## Review Frame

`web-browsing-evaluation-toolkit` uses synthetic examples to show a realistic portfolio workflow without relying on private data.

## Steps

1. Define the task or evaluation objective.
2. Review structured examples in `data/`.
3. Apply the documented rubric or scoring rule.
4. Run the summary scripts.
5. Capture findings in a short reviewer note.

## Evidence Standard

Every conclusion should be traceable to a row, label, score, source note, or synthetic event in the repository.
