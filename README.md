## Project Overview

This repository is a polished, recruiter-friendly portfolio project for `Web Browsing Evaluator` and adjacent micro1-style roles. It uses synthetic examples only and avoids confidential client data.

## Why This Project Exists

Web browsing evaluator roles need careful judgment around task success, UI evidence, source quality, and trajectory review. This repo shows how to turn browsing work into structured QA.
